# Справочник садовода

Приложение для садоводов Кабардино-Балкарии: сорта яблони и груши, декоративные растения, календарь работ, болезни и вредители.
Автор: Хажумаров А.А.

## Как обновлять с телефона
1. Откройте репозиторий на github.com → нужную папку → **Add file → Upload files**.
2. Выберите файл (с тем же именем, он заменит старый) → **Commit changes**.
3. Через 1–2 минуты сайт обновится сам. Ход сборки видно во вкладке **Actions**: зелёная галочка — всё в порядке, красный крестик — в данных ошибка (в логе написано, где).

## Что где лежит
| Папка | Что внутри |
|---|---|
| `data/apple.json`, `pear.json`, `ornamental.json` | карточки сортов и растений (по одному файлу на культуру) |
| `photos/` | свои фото сортов (`a9.webp`) и обложки разделов (`cat-apple.webp`) |
| `app/template.html` | код приложения и оформление |
| `static/` | иконки, манифест, сервис-воркер (работа без интернета) |
| `tools/` | проверка данных и сборка (запускаются автоматически) |

## Правила данных
- Только проверенные по источникам сведения; нет данных — «Уточнить».
- У каждого проверенного сорта есть `src` (источники) и `checked` (месяц проверки, например `2026-10`).
- Фото: только свои или с лицензией (Викисклад); для чужих обязательны автор и источник.
- Названия пестицидов и дозы не указываются.

## Проверка и сборка на компьютере
```
python3 tools/validate.py     # проверка данных
python3 tools/build.py        # сборка в dist/site
```
